# Ashmactool 图标

使用内置 imagegen 工具生成。`icon-source.png` 是原始透明图片；`AppIcon.png` 是用于打包的 1024×1024 版本。打包脚本用 macOS 的 `sips` / `iconutil` 生成完整 `.icns` 分辨率组。

设计：蓝色工具箱、银色提手、白色箭头和琥珀色锁扣。工具箱表达工具集合，箭头呼应指针工具，暖色锁扣呼应屏幕唤醒。

生成提示词：

> Use case: logo-brand. Asset type: macOS application icon for Ashmactool, a small native toolbox for custom mouse cursors and keeping the display awake. Primary request: create one polished original app icon, a compact softly rounded indigo toolbox with a silver top handle, with one large crisp white mouse-arrow emblem on the front and a tiny warm amber circular latch hinting at an awake screen. Style: refined macOS desktop icon, restrained dimensional depth and soft studio lighting, simple memorable silhouette with bold uncluttered shapes that remain legible at 32 pixels. Composition: one centered squircle icon occupying 88 percent of a square 1024 by 1024 canvas; transparent outside the icon, no surrounding mockup. No text, no letters, no watermarks, no Apple logos, no extra tools or busy details. Keep the large white cursor arrow inside the toolbox front as the dominant emblem. Premium, practical, calm.
